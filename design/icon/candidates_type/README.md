# 字体标候选

前面两批（几何平面、几何立体）是拿基本形拼出来的，没有设计可言。
这一批换思路：**中文阅读类 App 的图标基本都是字体标**——
微信读书、起点、掌阅、番茄都是一个字或极简符号，
craft 来自字形本身，不是手搓的几何体。

用系统自带中文字体取字，再做版式。`generate.ps1` 出图。

## 关键做法

**按字的墨迹包围盒定位，不按字体的排版框。**
汉字在 em 框里本来就偏上偏左，直接 `DrawString` 居中一定是歪的。
脚本里 `Get-GlyphPath` 先 `AddString` 拿到 `GraphicsPath`，
再用 `GetBounds()` 取真实墨迹范围，按它缩放和居中。

## 六版

| 文件 | 字 / 字体 | 路子 |
|---|---|---|
| M1 | 阁 / 黑体 | 字顶满画布，最直接 |
| M2 | 藏 / 楷体 | 笔锋带来的性格，黑体给不了 |
| M3 | 阁 / 黑体（反白） | 藏书印·阳文，冰蓝印面、字留白 |
| M4 | 藏 / 楷体 | 藏书印·阴文，只留一圈边框与字 |
| M5 | 阁 / 仿宋 | 最文气，笔画也最细 |
| M6 | 藏 / 雅黑粗 | 最重，任何尺寸都读得出 |

## 注意

`generate.ps1` 必须存成 **UTF-8 带 BOM**。
PowerShell 5.1 按 ANSI 读 .ps1，没有 BOM 的话脚本里的汉字全是乱码，
取出来的字形自然也是错的。
